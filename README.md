# Vectores-matrices-y-structs-en-C-
Programa en C++ con un menú interactivo que muestra el uso de vectores, matrices, funciones y registros (struct). Permite leer un vector y calcular su promedio, mayor y menor; sumar, multiplicar y transponer matrices cuadradas; y registrar estudiantes con sus notas en un struct, listándolos con su promedio.
